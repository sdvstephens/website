*Notes on Birkhoff and Mac Lane, A Survey of Modern Algebra.*

:::definition
Let $D$ be a set of elements $a, b, c, \dots$ for which the sum $a + b$ and the product $ab$ of any two elements $a$ and $b$ (distinct or not) of $D$ are defined. Then $D$ is called an **integral domain** if the following postulates (i)–(ix) hold:

1. (i) **Closure.** If $a$ and $b$ are in $D$, then $a + b$ and $ab$ are in $D$;
2. (ii) **Uniqueness.** If $a = a'$ and $b = b'$ in $D$, then $a + b = a' + b'$ and $ab = a'b'$;
3. (iii) **Commutativity.** For all $a$ and $b$ in $D$, $a + b = b + a$ and $ab = ba$;
4. (iv) **Associativity.** For all $a$, $b$ and $c$ in $D$, $a + (b + c) = (a + b) + c$ and $a(bc) = (ab)c$;
5. (v) **Distributivity.** For all $a$, $b$ and $c$ in $D$, $a(b + c) = ab + ac$;
6. (vi) **Zero / identity.** $D$ contains an element $0$ such that $a + 0 = a$ for all $a$ in $D$;
7. (vii) **Unity.** $D$ contains an element $1 \neq 0$ such that $a1 = a$ for all $a$ in $D$;
8. (viii) **Additive invertibility.** For each $a$ in $D$, the equation $a + x = 0$ has a solution in $D$;
9. (ix) **Cancellation law.** If $c \neq 0$ and $ca = cb$, then $a = b$.
:::
