- **Set:** a collection of objects (elements).
- **Elements / members:** the individual objects.

Sets can be of names, dogs, cats, numbers, curves, geometric figures, and more. When nothing special is assumed about a set, it is known as an **abstract set**. Abstract set theory is a subfield of set theory. (See Note 1 for more info.)
