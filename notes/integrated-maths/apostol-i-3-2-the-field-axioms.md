:::definition Axiom 1 (Commutative laws)
$x + y = y + x$ and $xy = yx$.
:::

:::definition Axiom 2 (Associative laws)
$x + (y + z) = (x + y) + z$ and $x(yz) = (xy)z$.
:::

:::definition Axiom 3 (Distributive law)
$x(y + z) = xy + xz$.
:::

:::definition Axiom 4 (Existence of identity elements)
$0$ and $1$ are in $\RR$, and $x + 0 = x$ and $1x = x$.
:::

:::definition Axiom 5 (Existence of negatives)
For every real number $x$ there is a real number $y$ such that $x + y = 0$.
:::

:::definition Axiom 6 (Existence of reciprocals)
For every real number $x \neq 0$ there is a real number $y$ such that $xy = 1$.
:::

From these $6$ axioms we can derive all the laws of elementary algebra and create a series of theorems.

:::theorem Theorem I.1 (Cancellation law for addition)
If $a + b = a + c$, then $b = c$. (In particular, this shows that the number $0$ of Axiom 4 is unique.)
:::

:::theorem Theorem I.2 (Possibility of subtraction)
Given $a$ and $b$, there is exactly one $x$ such that $a + x = b$. This $x$ is denoted by $b - a$. In particular, $0 - a$ is written simply $-a$ and is called the **negative** of $a$.
:::

:::theorem Theorem I.3
$b - a = b + (-a)$.
:::

:::theorem Theorem I.4
$-(-a) = a$.
:::

:::theorem Theorem I.5
$a(b - c) = ab - ac$.
:::

:::theorem Theorem I.6
$0 \cdot a = a \cdot 0 = 0$.
:::

:::theorem Theorem I.7 (Cancellation law for multiplication)
If $ab = ac$ and $a \neq 0$, then $b = c$. (In particular, this shows that the number $1$ of Axiom 4 is unique.)
:::

:::theorem Theorem I.8 (Possibility of division)
Given $a$ and $b$ with $a \neq 0$, there is exactly one $x$ such that $ax = b$. This $x$ is denoted by $b/a$ or $\frac{b}{a}$ and is called the **quotient** of $b$ and $a$. In particular, $1/a$ is also written $a^{-1}$ and is called the **reciprocal** of $a$.
:::

:::theorem Theorem I.9
If $a \neq 0$, then $b/a = b \cdot a^{-1}$.
:::

:::theorem Theorem I.10
If $a \neq 0$, then $(a^{-1})^{-1} = a$.
:::

:::theorem Theorem I.11
If $ab = 0$, then $a = 0$ or $b = 0$.
:::

:::theorem Theorem I.12
$(-a)b = -(ab)$ and $(-a)(-b) = ab$.
:::

:::theorem Theorem I.13
$(a/b) + (c/d) = (ad + bc)/(bd)$ if $b \neq 0$ and $d \neq 0$.
:::

:::theorem Theorem I.14
$(a/b)(c/d) = (ac)/(bd)$ if $b \neq 0$ and $d \neq 0$.
:::

:::theorem Theorem I.15
$(a/b)/(c/d) = (ad)/(bc)$ if $b \neq 0$, $c \neq 0$, and $d \neq 0$.
:::

The proofs for some of these (Theorems I.1–I.4) can be found in Apostol, Vol. I, page 19.
