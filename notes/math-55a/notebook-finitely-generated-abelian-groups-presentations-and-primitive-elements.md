:::theorem
Any finitely generated abelian group is isomorphic to a product of cyclic groups:
$$G\cong\big(\ZZ/n_1\times\cdots\times\ZZ/n_k\big)\times\ZZ^{\ell}.$$
(Since $\ZZ/mn\cong\ZZ/m\times\ZZ/n\iff\gcd(m,n)=1$ (i.e., $m,n$ coprime), we can factor further, e.g., to arrange that all the $n_i$ are powers of primes.)
:::

:::remark Recall
$(G,+)$ is a $\ZZ$-module, via $\ZZ\times G\to G$.
:::

If $G$ is finitely generated by $g_1,\dots,g_m$, we get a surjection $\varphi:\ZZ^m\to G$, and
$$G\cong\ZZ^m/\ker(\varphi).$$

:::proposition Prop 1
If $M$ is a finitely generated module (over $\ZZ$), then there exist $m,n$ and $T\in\Hom(\ZZ^m,\ZZ^n)$ such that $M\cong\ZZ^n/\operatorname{Im}(T)$. Equivalently, there is an exact sequence
$$\ZZ^m\xrightarrow{\ T\ }\ZZ^n\longrightarrow M\longrightarrow 0.$$
:::

The proof rests on the following.

:::lemma
Any submodule (subgroup) of $\ZZ^n$ is finitely generated (and free of rank $\le n$, too).
:::

:::proof
By induction on $n$.

- $n=1$: the subgroups of $(\ZZ,+)$ are $\{0\}$ and $\ZZ a$, $a\in\ZZ_{>0}$.
- Assume the lemma is true for $\ZZ^{n-1}$, and consider a submodule $M\subset\ZZ^n$.
- Consider the homomorphism
$$\pi:\ M\xrightarrow{\text{incl.}}\ZZ^n\longrightarrow\ZZ^{n-1},\qquad (a_1,a_2,\dots,a_n)\longmapsto(a_2,\dots,a_n),$$
i.e., $\pi:M\to\ZZ^{n-1}$.

So $\operatorname{Im}(\pi)\subset\ZZ^{n-1}$ is a submodule, hence finitely generated (free) by induction. And $\ker(\pi)=M\cap(\ZZ\times0\times\cdots\times0)$ is a subgroup of $\ZZ$, hence free of rank 0 or 1. So $\ker(\pi)$ and $\operatorname{Im}(\pi)$ are finitely generated (free), which gives that $M$ is free (finitely generated). The proof goes like the one for the rank theorem.

Let $e_1,\dots,e_k$ be generators (a basis) of $\ker\pi$, and let $g_1=\pi(f_1),\dots,g_m=\pi(f_m)$ be generators (a basis) of $\operatorname{Im}(\pi)$. We claim that $e_1,\dots,e_k,f_1,\dots,f_m$ generate (are a basis of) $M$.

For all $x\in M$ we have $\pi(x)\in\operatorname{Im}(\pi)$, so there are $a_i\in\ZZ$ such that
$$\pi(x)=\sum a_ig_i=\pi\Big(\sum a_if_i\Big)\implies x-\sum a_if_i\in\ker(\pi),$$
so there are $b_j\in\ZZ$ such that $x-\sum a_if_i=\sum b_je_j$, i.e.,
$$x=\sum a_if_i+\sum b_je_j.$$

:::

:::proof Proof of Prop 1
If $M$ is finitely generated, with generators $e_1,\dots,e_n$, then $\varphi:\ZZ^n\to M$ is surjective, and $\ker(\varphi)=N\subset\ZZ^n$ is a subgroup/submodule of $\ZZ^n$, so it is finitely generated by the lemma. So (go over this) $\ker\varphi=\operatorname{Im}(T:\ZZ^m\to\ZZ^n)$ for some $T$, which gives the exact sequence
$$\ZZ^m\xrightarrow{\ T\ }\ZZ^n\xrightarrow{\ \varphi\ }M\longrightarrow0.$$
So, given $\ker\varphi=\operatorname{Im}T$, we get $M\cong\ZZ^n/\operatorname{Im}T$.
:::

## Divisibility

Divisibility of elements of $\ZZ^n$, in a free module (over $\ZZ$).

:::definition
The **divisibility** of $x\neq0$, $x=(a_1,\dots,a_n)\in\ZZ^n$, is the largest $d\in\ZZ_{+}$ such that there is $y\in\ZZ^n$ with $x=dy$; concretely, $d=\gcd(a_1,\dots,a_n)$. We say $x$ is **primitive** if its divisibility is $1$.
:::

:::lemma
An element of a free finitely generated module ($\ZZ^n$) can be part of a basis if and only if it is primitive.
:::

:::proof
An element of a basis $(e_1,\dots,e_n)$ must be primitive: $e_i=d\big(\sum_j a_je_j\big)$ with $d>1$ would contradict linear independence.

Conversely, let $v=a_1e_1+\cdots+a_ne_n$ be a primitive element, written in a basis $e_1,\dots,e_n$. Since $v\neq0$, WLOG we can assume $a_1\ne0$ and
$$|a_1|=\min\{|a_k| : a_k\neq0\},$$
i.e., $|a_1|$ is minimal among the nonzero coefficients.

Guys, we’re changing basis now!!
