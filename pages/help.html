:help

Vim-style keybindings and commands for this site.

Navigation Keys

  • j / k — scroll down / up
  • gg — jump to top
  • G — jump to bottom
  • [ / ] — previous / next post or note section
  • Space — show leader menu (see below)
  • / — search every page (titles, headings, text)
  • : — command mode (Tab completes)
  • ? — this page
  • Escape — close command/search/explorer

Leader Menu (Space)

  • Space e — file explorer
  • Space / — search
  • Space : — command line
  • Space t — switch light / dark theme
  • Space z — zen mode
  • Space Space — page down (Shift + Space pages up)
  • Space g — goto: h home, a about, r research, b blog, p poems, n notes, m music, w homework, d educational, l latest post
  • Space y — yank (copy): y link to this page, s link to this section, m Markdown link, e email address
  • Space o — open: c CV, g GitHub, y YouTube, l Letterboxd, s site source
  • Backspace — back up a level; Escape — close

Explorer Keys (when focused)

  • ↑ / k — move up
  • ↓ / j — move down
  • ← / h — close folder, or go to parent
  • → / l — open folder
  • Enter / o — open the page
  • gg / G — first / last entry
  • / — filter by name
  • W / E — collapse / expand everything
  • q — close explorer; Escape — back to the page

On a wide screen the explorer docks beside the page and stays open as you move between pages.

Commands

Navigation

  • :h / :home — go home
  • :a / :about — about page
  • :r / :research — research
  • :b / :blog — blog
  • :p / :poems — poems
  • :n / :notes — lecture notes
  • :m / :music — music
  • :hw / :homework — homework
  • :t / :technical — educational
  • :e / :edu — educational
  • :ex / :explore — file explorer
  • :ls — list all routes
  • :latest — most recent blog post

External

  • :cv / :resume — download CV
  • :email — copy email to clipboard
  • :mail — open email client
  • :gh / :github — GitHub profile
  • :yt / :youtube — YouTube channel
  • :lb / :letterboxd — Letterboxd profile
  • :source — site source code

Display

  • :zen — toggle minimal reading mode
  • :set bg=light / :set bg=dark — theme
  • :help / :? — this page
  • :version — site version
  • :echo <text> — print message

Quit

  • :q / :quit — close tab
Pro tips
Type fast, like vim gg to return to top / is fuzzy, : is exact
